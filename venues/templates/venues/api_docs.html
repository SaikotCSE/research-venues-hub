VenuePulse API

JSON over HTTPS. Public endpoints need no auth; /api/v1/me/* requires Authorization: Bearer <token> (get yours on your profile).

Public

GET /api/venues/Paginated list. Filters: q, type, domain, tag, core, ccf, quartile, min_if, country, continent, review, oa, status, sort, dir, page, page_size
GET /api/venues/<slug>/Venue detail incl. all deadline cycles
GET /api/tags/Subfield tags with venue counts
GET /api/stats/Totals
GET /api/insights/Aggregates that power the Insights page
GET /api/suggest/?q=Autocomplete used by the command palette
GET /calendar.ics?…filtersiCal feed of all matching upcoming milestones
GET /feed/deadlines.atom?…filtersAtom feed of the next 50 deadlines

Authenticated

GET /api/v1/me/Your profile
GET /api/v1/me/targets/Starred venues
POST /api/v1/me/targets/Body {"slug": "cvpr"} – star a venue
DELETE /api/v1/me/targets/<slug>/Unstar a venue
GET /api/v1/me/submissions/Your tracked submissions
curl -H "Authorization: Bearer $TOKEN" {{ host }}/api/v1/me/targets/
curl -X POST -H "Authorization: Bearer $TOKEN" -d '{"slug":"neurips"}' {{ host }}/api/v1/me/targets/
