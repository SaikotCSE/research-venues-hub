Quick start

# A* conferences with a paper deadline in the next 60 days
curl "{{ host }}/api/venues/?core=A*&within=60&sort=deadline"

# Star a venue with your token
curl -X POST -H "Authorization: Bearer $VENUEPULSE_TOKEN" -H "Content-Type: application/json" \
     -d '{"slug": "neurips"}' {{ host }}/api/v1/me/targets/
import requests

url = "{{ host }}/api/venues/"
params = {"type": "Journal", "quartile": "Q1", "min_if": 10, "page_size": 50}
while url:
    page = requests.get(url, params=params, timeout=10).json()
    for venue in page["results"]:
        print(venue["acronym"], venue["impact_factor"], venue["url"])
    url, params = page["next"], None   # follow pagination links
// Public endpoints send CORS headers, so this works from any website.
const res = await fetch("{{ host }}/api/venues/?status=open&sort=deadline&page_size=5");
const { results } = await res.json();
results.forEach(v => console.log(v.acronym, v.next_deadline?.at));

Conventions

      

        
Pagination
Lists return count, page, num_pages, page_size (1–200, default 25) and absolute next/previous links.

        
Errors
Always JSON: {"error": "…"} with status 400, 401, 404, 405 or 429.

        
Caching
Public endpoints send a weak ETag and Cache-Control: max-age=300; repeat requests with If-None-Match get 304 Not Modified.

        
Rate limits
{{ limits.api_public }} public requests and {{ limits.api_token }} token requests per client. Headers: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset; 429 responses include Retry-After.

        
CORS
Public read-only endpoints allow any origin. Token endpoints do not — call them from a server.

        
Times
ISO 8601 in UTC. Each cycle states whether its official cut-off is AoE (UTC−12) or UTC, and whether the dates are projected.

Filter parameters

      
Accepted by /api/venues/, the CSV/JSON exports and the calendar/Atom feeds. Repeat a parameter to OR values, e.g. ?core=A*&core=A.

Authentication

      
Personal endpoints under /api/v1/me/ require Authorization: Bearer <token>. Find or regenerate your token on your profile; regenerating revokes the old one immediately. Requests without a valid token get 401 with a WWW-Authenticate header.
